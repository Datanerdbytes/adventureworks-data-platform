## What a skill does

A skill is a reusable set of instructions in `SKILL.md`, sometimes with scripts, references, or assets. It guides how Codex performs a recurring task; it is not an app feature, a scheduled job, or a guarantee that tools/accounts are connected. `AGENTS.md` holds repository-wide context and rules; skills hold focused workflows that apply when relevant.

Files linked below live on this Mac. This catalog is saved in the project, but it does not bundle or install those skill files for another machine. Plugin cache paths include versions and can change after plugin updates. The active session catalog is the authority for which plugin skills and tools are exposed.

## How to invoke and maintain skills

Mention the skill in ordinary language or use `$skill-name`, as above. For plugin skills use the exact exposed name, including a plugin prefix when shown in the session catalog. Relevant skills may also be selected automatically; automatic selection is not continuous learning.

Skills **remain as written until their files are updated**. To improve one, identify an actual recurring issue or useful lesson, request a focused update, validate the result, and check that existing uses still make sense. Example: “Update dash-warehouse-report with the export issue we just fixed.” Avoid adding one report's metric formulas or temporary branch state as universal rules. Changes to plugin-managed skills can be replaced by plugin updates; keep personal adaptations separately when appropriate.

The five project-derived workflows are `dash-warehouse-report`, `dash-aggrid-ledger`, `python-security-ci`, `bigquery-cache-verification`, and `dash-supabase-auth`. They were created from AdventureWorks patterns and installed in the personal Codex skills directory. Structure validation does not establish end-to-end behavior in another project; refine them using actual results.

Skills do not independently authorize production queries, migrations, credentials, external messages, deployment, or Git writes. Existing user instructions and repository safety rules still apply. No new service connection is required merely to read a skill.
